# 자동차 경주

## 프로젝트 구조

---

### 1. MVC 패턴

- `model`은 실제 게임의 핵심 비즈니스 로직을 담당하며, 개별 자동차가 랜덤 값에 따라 전진하고,
  여러 자동차를 하나의 그룹으로 관리하는 로직과 게임을 진행하고 우승자를 판별하는 기능을 포함한다.


- `view`는 사용자와 소통을 책임진다. 입력 받을 때 형식이 올바른지 검증하고, 매 라운드마다 자동차의 위치를 화면에 표시한다.
  이후 최종 우승자를 알기 쉽게 출력한다.


- `controller`는 전체 게임 흐름을 관리한다. `view`와 `model`을 하나로 연결하고 게임을 실행하는 역할을 담당한다.


- `exception`은 예외 처리 메시지를 담고 있다. 여러 지점에서 발생하는 예외 케이스에 대해 한 클래스에서 관리함으로써,
  어떤 예외가 존재하는 지 쉽게 파악하고 코드의 유지보수성을 높였다.

### 2. 적용한 디자인 패턴

- 전략 패턴: `RandomNumberGenerator` 인터페이스로 랜덤 생성 전략을 추상화한다. 이를 통해 단위 테스트를 원활하게 진행할 수 있다.


- 일급 컬렉션: `CarGroup`에 `List<Car>`를 필드로 선언하여 `Car` 객체들에 대한 상태와 행위를 한 곳에서 관리한다.
  이를 통해 "모든 자동차 이동", "우승자 찾기" 와 같은 그룹 단위 동작을 응집도 높게 구현할 수 있다.

### 3. 단위 테스트 / 통합 테스트

- `model`은 비즈니스 로직을 담당하는 핵심이므로, 명확한 검증을 위해 단위 테스트를 작성한다.


- `view`는 사용자에게 단순히 입력과 출력을 제공하는 역할이고, `controller`는 단지 `model`과 `view`를 연결한 것에 불과하므로
  통합 테스트를 작성한다.

## 기능 목록

---

### 1. 입력 기능

#### 자동차 이름, 개수 입력

- [x] 자동차의 이름을 `쉼표(,)`를 기준으로 구분하여 입력받는다.
- [x] 입력이 null 이거나 빈 문자열인 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 자동차의 최대 입력 개수는 100개 이하로 지정하며, 개수를 초과하는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 자동차 이름의 길이는 5자 이하만 가능하며, 길이를 초과하는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 자동차 이름이 중복될 경우 `IllegalArgumentException`을 발생시킨다.

#### 시도 횟수 입력

- [x] 경주를 시도할 횟수를 양수 형태로 입력 받는다.
- [x] 입력이 null, 0, 음수인 경우 `IllegalArgumentException`을 발생시킨다.
- [x] `five`, `four`와 같이 숫자 형태 입력이 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [x] int 범위를 벗어나는 경우 `IllegalArgumentException`을 발생시킨다.

### 2. 경주 게임 진행

#### 각 시도(round) 진행

- [x] 각 시도마다 모든 자동차를 대상으로 랜덤 값이 4 이상(0 ~ 9 사이)인 경우 자동차를 전진한다.
- [x] 주어진 횟수만큼 자동차들이 경주를 진행한다.

#### 경주 우승자 결정

- [x] 경주가 끝난 후 가장 멀리 이동한 자동차가 우승자가 된다.

### 3. 출력 기능

#### 경주 진행상황 출력

- [x] 각 시도(round) 별로 전진한 자동차 상태를 출력한다. 자동차 이름과 `-`로 전진한 상태를 표시한다.
    - 출력 형식 =>  {자동차 이름} : `-`

#### 우승자 출력

- [x] 모든 시도(round)가 끝난 후 최종 우승자를 출력한다. 우승자가 여러명일 경우 `쉼표(,)`를 이용하여 구분한다.
    - 출력 형식 => 최종 우승자 : {우승자1}, {우승자2}, ...

### 4. 테스트 코드 작성

- [x] 자동차 이름, 개수 입력이 유효한지 검증하는 테스트 코드를 작성한다.
- [x] 시도 횟수 입력이 유효한지 검증하는 테스트 코드를 작성한다.
- [x] 각 시도(round)가 정상 동작하는 지 검증하는 테스트 코드를 작성한다.
- [x] 경주 우승자 결정 로직이 정상 동작하는 지 검증하는 테스트 코드를 작성한다.
